    #ผลงานสร้างสรรค์#
    การบำรุงรักษาและจัดการความร้อนแล็ปท็อป

    ทำการถอดประกอบแล็ปท็อปเพื่อทำความสะอาดและเปลี่ยนซิลิโคนระบายความร้อน (Thermal Paste) ให้กับ CPU/GPU ด้วยตนเอง ช่วยแก้ปัญหาความร้อนสะสม (Thermal Throttling) และดึงประสิทธิภาพของเครื่องให้กลับมาทำงานได้อย่างเต็มที่ แสดงให้เห็นถึงความเข้าใจในโครงสร้างฮาร์ดแวร์และความระมัดระวังในการปฏิบัติงานกับอุปกรณ์อิเล็กทรอนิกส์
    เมื่อวันที่ 24/ส.ค./2569

    การแข่งขันการตอบคำถามวิทยาศาสตร์และเทคโนโลยี

    ทักษะที่ได้รับ

    • การคิดวิเคราะห์และประมวลผลข้อมูลทางวิทยาศาสตร์อย่างรวดเร็ว
    • การแก้ปัญหาเฉพาะหน้าภายใต้ความกดดันและเวลาที่จำกัด
    • ความเข้าใจเชิงลึกในหลักการพื้นฐานด้านวิทยาศาสตร์และเทคโนโลยี
    • ทักษะการจดจำและการเชื่อมโยงความรู้เพื่อหาคำตอบ

    ประสบการณ์ที่ได้รับ

    • ฝึกฝนความกล้าตัดสินใจและความมั่นใจในตัวเองเมื่อต้องตอบคำถาม

    • การใช้เครื่องมือตรวจสอบและแก้ไขปัญหา

    • รายละเอียดเพิ่มเติม บน Facebook

    วันวิทยาศาสตร์

    สิ่งที่ได้รับ

    • ‌รับรู้วิชาในสาขาที่เรียนจริง เช่น เจอCode น้อย เจอ การเขียน Code มาก
    • ‌พูดคุยกับอาจารย์มหาวิทยาลัยในคณะเทคโนโลยี เรื่อง การประดิษฐ์หุ่นยนต์ อัตโนมัติ

    ประสบการณ์ที่ได้รับ

    • เข้าใจการเรียนรู้ของเด็กในสาขาวิชาต่างๆ เช่น วิทยาการคอมพิวเตอร์เกี่ยวกับอะไร เทคโนโลยีสารสนเทศ เกี่ยวกับอะไร
    • เสริมสร้างทักษะการเข้าสังคมกับรุ่นพี่ในมหาวิทยาลัย

    อบรมเชิงปฎิบัติการใช้ IoT ในการสร้างนวัตกรรม

    ได้รับการคัดเลือกเข้าร่วมการอบรมเชิงปฏิบัติการด้าน Internet of Things (IoT) เพื่อศึกษาแนวทางการประยุกต์ใช้เทคโนโลยีในการสร้างนวัตกรรมและอุปกรณ์อัจฉริยะ โดยได้เรียนรู้การใช้งานไมโครคอนโทรลเลอร์ การเชื่อมต่ออุปกรณ์ผ่านเครือข่ายอินเทอร์เน็ต และการพัฒนาระบบควบคุมอัตโนมัติ ผลงานที่ได้จากการอบรมคือการพัฒนาอุปกรณ์เปิด–ปิดม่านผ่านสมาร์ตโฟน ซึ่งเป็นการนำองค์ความรู้จากกิจกรรมมาประยุกต์ใช้และต่อยอดเป็นผลงานจริง สะท้อนถึงความสนใจด้านเทคโนโลยีและความสามารถในการเรียนรู้ด้วยตนเอง

    การแข่งขันสร้างสรรค์เกมจากคอมพิวเตอร์

    กิจกรรมนี้เปิดโอกาสให้ผู้เข้าร่วมได้แสดงความสามารถด้านการออกแบบและพัฒนาเกม โดยผู้จัดทำได้ศึกษากระบวนการออกแบบเกม การวางระบบการทำงาน การแก้ไขปัญหา และการพัฒนาผลงานให้สามารถใช้งานได้จริง การเข้าร่วมการแข่งขันครั้งนี้ช่วยพัฒนาทักษะด้านตรรกะ ความคิดสร้างสรรค์ และการประยุกต์ใช้เทคโนโลยีในการสร้างผลงานดิจิทัล

    อบรมความเป็นผู้นำ (สภานักเรียน)

    ได้รับการพัฒนาทักษะด้านภาวะผู้นำ การทำงานร่วมกับผู้อื่น การวางแผนกิจกรรม และการรับผิดชอบต่อหน้าที่ในฐานะตัวแทนนักเรียน กิจกรรมดังกล่าวช่วยเสริมสร้างความกล้าแสดงออก การตัดสินใจอย่างมีเหตุผล และความสามารถในการประสานงานกับบุคคลหลากหลายกลุ่ม ซึ่งเป็นทักษะสำคัญต่อการทำงานในอนาคต

    Thailand CE-7 Moonshot Challenge

    กิจกรรมนี้เป็นการแข่งขันตอบปัญหาที่เน้นการใช้ความรู้ด้านวิทยาศาสตร์และเทคโนโลยีดาราศาสตร์ พื้นตอบปัญหาและเข้าถึงข้อใมูลพื้นฐานเกี่ยวกับดาราศาสตร์และวิทยาศาสตร์อวกาศและเทคโนโลยีแห่งอากาศ

    แข่งขันซูโดกุ

    ไเข้าร่วมการแข่งขันเพื่อพัฒนาทักษะการคิดเชิงตรรกะ การวิเคราะห์ข้อมูล และการแก้ปัญหาอย่างเป็นขั้นตอน ผ่านกระบวนการคิดอย่างเป็นระบบและการตัดสินใจภายใต้ข้อจำกัดของเวลา กิจกรรมนี้ช่วยเสริมสร้างพื้นฐานด้านการคิดคำนวณและการใช้เหตุผล
