# Vutthikorn Portfolio

Portfolio Website สำหรับสะสมข้อมูลส่วนตัว ผลงาน กิจกรรม และเกียรติบัตร โดยออกแบบให้มีความเป็นทางการ เหมาะสำหรับใช้เป็นเว็บประชาสัมพันธ์และการสมัครเข้ามหาวิทยาลัยหรือการศึกษาต่อ

## Overview

เว็บไซต์นี้ถูกสร้างขึ้นเพื่อสะท้อนตัวตนของผู้พัฒนาในรูปแบบที่เรียบหรูและมีความน่าเชื่อถือ โดยเน้นการนำเสนอผลงานและประสบการณ์ผ่าน UI ที่มีธีมสีน้ำเงิน ขาว ดำ และทอง เพื่อให้ดูมีระดับและความเป็นมืออาชีพมากขึ้น

## Highlights

- Layout แบบ Portfolio ที่สื่อสารความเป็นนักเรียน-นักพัฒนาได้ชัดเจน
- กราฟิกและการออกแบบที่เน้นความหรูด้วยโทนสีเข้มและเอฟเฟกต์ภายใต้เงาและความสว่าง
- ส่วนแสดงการสะสมเกียรติบัตรและกิจกรรมที่จัดกลุ่มชัดเจนตามปีและประเภท
- ปุ่มกรองแยกตามประเภท เช่น อบรม แข่งขัน และอื่นๆ
- การตอบสนองบนหน้าจอหลากหลายขนาด (Responsive Design)
- Popup Detail สำหรับภาพเกียรติบัตรและกิจกรรมเพื่อให้ผู้ชมดูข้อมูลได้ชัดเจนขึ้น
- Animation และ hover effect เพื่อเพิ่มความรู้สึกมีชีวิตชีวาและความพรีเมียม
- Background คงโทนแบบเดิมไว้ แต่เพิ่ม motion แบบเคลื่อนไหวตาม scroll เพื่อให้ได้บรรยากาศที่มีชีวิตและมีระดับมากขึ้น โดยยังให้ความรู้สึกเหมือนมีการไล่ระดับและการเปลี่ยนแปลงตลอดเวลา

## Recent Visual Upgrade

- ปรับพื้นหลังกลับไปสู่โทนที่คล้ายเดิมมากขึ้น เพื่อให้หน้าตาเว็บไซต์คงความเรียบและเป็นมืออาชีพ
- เพิ่ม motion ที่มาจากการเลื่อนหน้าจอและการไล่ระดับของ section ให้เห็นชัดเจนยิ่งขึ้น จนรู้สึกว่าหน้าเว็บมีการเคลื่อนไหวตามระดับการเลื่อนอย่างต่อเนื่อง
- ใช้ animation แบบมีความแรงและสวยกว่าเดิม เพื่อให้ทุกส่วนที่เข้ามาใน viewport ดูมีชีวิตและคมชัดมากขึ้น
- ยังคงคงธีมหลักของเว็บไซต์เป็น ดำ / ขาว / ฟ้า / เหลือง ตามที่กำหนดไว้อย่างเคร่งครัด

## Features

### 1. Hero Section
- แสดงข้อมูลเบื้องต้นพร้อมภาพโปรไฟล์
- มีปุ่มสำหรับไปยังส่วนที่ต้องการ เช่น เกี่ยวกับฉัน ผลงาน และเกียรติบัตร

### 2. About & Skills
- อธิบายข้อมูลส่วนตัวและความสนใจ
- แสดงประสบการณ์และความสามารถในรูปแบบที่อ่านง่าย

### 3. Project Showcase
- แสดงผลงานสำคัญและโครงการที่กำลังพัฒนา
- มีป้ายสถานะที่ช่วยสื่อถึงขั้นตอนการพัฒนา

### 4. Certificate Gallery
- จัดเก็บเกียรติบัตรแบบเป็นหมวดหมู่
- กรองตามประเภทและปีการศึกษา
- แสดงผลเริ่มต้นที่อันแรกที่เห็นมีความโดดเด่น

### 5. Responsive Experience
- ปรับให้ใช้งานได้ดีทั้งบนคอมพิวเตอร์ แท็บเลต และมือถือ

## Code Logic Summary

### HTML Structure
- `index.html` เป็นโครงสร้างหลักของเว็บทั้งหมด
- มีส่วนผนวกหลัก เช่น Header, Hero, About, Skills, Projects, Certificates, Footer
- ปุ่มและ navigation ใช้ `href="#..."` เพื่อเลื่อนไปยัง section ที่ต้องการ
- ตัวแปร role text ที่หมุนสลับคำอยู่ใน hero section เช่น `Portfolio • <span class="role-switcher" data-roles="Student Developer,Front-end Developer,UI/UX Enthusiast,Problem Solver"></span>`

### CSS System
- `assets/css/main.css` จัดการสีสันและธีมเว็บ โดยใช้โทนหลัก ดำ / ขาว / ฟ้า / เหลือง
- `body::before` และ `body::after` สร้างพื้นหลังแบบ grid + glow เพื่อเพิ่มความมีมิติ
- `scroll-reveal` ใช้ animation เมื่อ section ปรากฏใน viewport
- `card-certificates` ให้การ์ดเกียรติบัตรมีรูปแบบคัดสรร, ระดับชัดเจน, และ hover effect ที่ดู premium
- `@media (max-width: 768px)` ทำให้เว็บปรับใช้ได้ดีบนมือถือ

### JavaScript Behavior
- `document.getElementById()` และ `document.querySelector()` ใช้เพื่อหา element จาก HTML
- ฟังก์ชัน `openPopupX` / `closePopupX` ทำงานเปิด-ปิด popup ของแต่ละ certificate
- `filtercards(category)` เป็นฟังก์ชันหลักของการกรองเกียรติบัตรตามประเภทหรือปี
- `IntersectionObserver` ใช้สำหรับ scroll reveal และ highlight การ์ดแรกที่เห็น
- `setInterval()` ใช้หมุนเปลี่ยนคำใน hero text แบบค่อย ๆ สลับ
- `setLoadingOverlay()` ใช้แสดง loading overlay ขณะเปลี่ยนหน้า/โหลดเนื้อหา
- `updateCountdown()` เป็นระบบนับถอยหลังสำหรับกิจกรรมหรือวันสำคัญ

### Workflow Summary
1. HTML กำหนดโครงสร้างและ content
2. CSS กำหนดสไตล์และ animation
3. JavaScript ทำ interaction, filter, reveal, popup, rotating role text, loading overlay
4. หน้าเว็บจึงมีความเป็น static portfolio แบบ premium และ easy-to-maintain
