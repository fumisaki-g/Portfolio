# Vutthikorn Portfolio Website

## เกี่ยวกับโปรเจกต์นี้

เว็บไซต์ Portfolio ส่วนตัวของ **นายวุฒิกร ปั้นนาค (Vutthikorn Pannakh)** นักเรียนชั้นมัธยมศึกษาปีที่ 6 แผนการเรียนวิทยาศาสตร์–คณิตศาสตร์ จัดทำขึ้นเพื่อรวบรวมประวัติ ทักษะ กิจกรรม ผลงาน และเกียรติบัตรของผู้จัดทำไว้ในที่เดียว สำหรับใช้ประกอบการยื่นสมัครเข้าศึกษาต่อระดับมหาวิทยาลัย

เว็บไซต์นี้ไม่ใช่แค่หน้าประวัติ แต่คือผลงานที่ผู้จัดทำ **ออกแบบ เขียนโค้ด และแก้ปัญหาด้วยตนเองทั้งหมด** ตั้งแต่โครงสร้างหน้าเว็บไปจนถึงการเชื่อมต่อฐานข้อมูล เพื่อสะท้อนให้เห็นว่าผู้จัดทำมีความสนใจด้านเทคโนโลยีจากการลงมือทำจริง ไม่ใช่เพียงความรู้ทางทฤษฎี

### จุดเด่นของเว็บไซต์

- **ทำเองตั้งแต่ต้น** — วางโครงสร้าง HTML และออกแบบ CSS ด้วยตนเองทั้งหมด
- **มีระบบหลังบ้านจริง** — เชื่อมต่อฐานข้อมูล Supabase เพื่อบันทึกผู้เข้าใช้งาน ไม่ใช่เว็บสถิตธรรมดา
- **แยกข้อมูลออกจากหน้าเว็บ** — ใช้ไฟล์ JSON ร่วมกับ Fetch API ทำให้แก้ไข/เพิ่มข้อมูลได้ง่ายโดยไม่ต้องแก้โค้ดหน้าเว็บ
- **ใช้งานได้จริงและอัปเดตต่อเนื่อง** — เผยแพร่บน GitHub Pages และมีบันทึกพัฒนาการ (Development Log) ตั้งแต่วันแรกจนถึงปัจจุบัน
- **ใช้ AI อย่างมีขอบเขต** — ใช้เป็นเครื่องมือช่วยศึกษา/แนะแนวทางในบางจุด (เช่น JavaScript บางส่วน) แต่ผู้จัดทำเป็นผู้ตัดสินใจ ตรวจสอบ และแก้ไขโค้ดเองเสมอ

### เทคโนโลยีที่ใช้ (โดยสรุป)

`HTML5` · `CSS3` · `JavaScript` · `JSON + Fetch API` · `Supabase` · `Git / GitHub` · `GitHub Pages`

*(รายละเอียดเชิงลึกของแต่ละเทคโนโลยีอยู่ในหัวข้อ "เทคโนโลยีและเครื่องมือที่ใช้" ด้านล่าง)*


## ที่มาและแรงบันดาลใจ

ผู้จัดทำมีความสนใจเกี่ยวกับคอมพิวเตอร์และเทคโนโลยีมาตั้งแต่ก่อนเริ่มพัฒนาเว็บไซต์ Portfolio อย่างจริงจัง ความสนใจดังกล่าวเริ่มจากการใช้งานและทดลองกับคอมพิวเตอร์ การศึกษาเรื่องระบบปฏิบัติการ การติดตั้งและปรับแต่งระบบ การดูแลรักษา Laptop รวมถึงการเรียนรู้ว่าซอฟต์แวร์และฮาร์ดแวร์ทำงานร่วมกันอย่างไร

ต่อมาจึงเริ่มสนใจการสร้างเว็บไซต์และการพัฒนาโปรแกรม เพราะต้องการสร้างสิ่งที่สามารถใช้งานและนำเสนอความคิดของตนเองได้ เว็บไซต์ Portfolio จึงเกิดขึ้นจากความต้องการที่จะสร้างพื้นที่ของตัวเองสำหรับรวบรวมผลงาน กิจกรรม และประสบการณ์ต่าง ๆ แทนการเก็บข้อมูลไว้แยกกันหลายที่ นอกจากนี้ยังต้องการใช้โปรเจกต์นี้เป็นสนามทดลองสำหรับฝึก HTML, CSS, JavaScript, การจัดการข้อมูล และการออกแบบประสบการณ์การใช้งาน

การพัฒนาเว็บไซต์เริ่มจากโครงสร้างพื้นฐาน แล้วค่อย ๆ เพิ่มส่วนต่าง ๆ ตามข้อมูลและประสบการณ์ของผู้จัดทำ เช่น ส่วนแนะนำตัว ส่วนแสดงทักษะ ส่วนกิจกรรม ส่วนผลงาน ส่วนเกียรติบัตร ระบบเปิดดูรายละเอียดกิจกรรม ระบบกรองหมวดหมู่เกียรติบัตร เมนูนำทางสำหรับอุปกรณ์ขนาดเล็ก และการโหลดข้อมูลบางส่วนจากไฟล์ JSON

## วัตถุประสงค์ของโปรเจกต์

1. สร้างเว็บไซต์สำหรับนำเสนอข้อมูลส่วนตัวและผลงานในรูปแบบที่เป็นระบบ
2. รวบรวมกิจกรรม เกียรติบัตร โครงงาน และความสนใจด้านเทคโนโลยีไว้ในที่เดียว
3. ฝึกการวิเคราะห์และวางโครงสร้างหน้าเว็บไซต์ก่อนลงมือพัฒนา
4. ฝึกการออกแบบส่วนติดต่อผู้ใช้ให้สามารถอ่านและใช้งานได้ง่าย
5. ฝึกเขียนเว็บไซต์ด้วย HTML, CSS และ JavaScript โดยไม่ใช้ Framework เป็นหลัก
6. เรียนรู้การแยกข้อมูลออกจากโครงสร้างหน้าเว็บด้วยไฟล์ JSON
7. ทดลองสร้างเว็บไซต์ที่มีการโต้ตอบกับผู้ใช้งาน เช่น เมนู ปุ่ม ตัวกรอง และหน้าต่างแสดงรายละเอียด
8. ฝึกการจัดการไฟล์ รูปภาพ และโครงสร้างโฟลเดอร์ของโปรเจกต์จริง
9. ใช้เป็นผลงานประกอบการแนะนำตัวและการยื่นเข้าศึกษาต่อระดับมหาวิทยาลัย
10. สร้างพื้นที่ที่สามารถปรับปรุงและเพิ่มข้อมูลใหม่ได้ในอนาคต

## ภาพรวมการทำงานของเว็บไซต์

หน้าเว็บไซต์หลักถูกออกแบบเป็นหน้า Portfolio แบบเลื่อนต่อเนื่อง โดยแบ่งเนื้อหาออกเป็นส่วนต่าง ๆ เพื่อให้ผู้เข้าชมสามารถทำความรู้จักผู้จัดทำตั้งแต่ข้อมูลเบื้องต้น ไปจนถึงผลงานและประสบการณ์ที่เกี่ยวข้อง

ส่วนหน้าแรกเป็นพื้นที่แนะนำตัวแบบสั้น ๆ มีชื่อผู้จัดทำ บทบาทที่สนใจ และข้อความที่สะท้อนแนวคิดเกี่ยวกับการเรียนรู้ นอกจากนี้ยังมีปุ่มที่ช่วยนำทางไปยังส่วนผลงานและทักษะโดยตรง เพื่อให้ผู้เข้าชมเข้าถึงข้อมูลสำคัญได้ง่าย

ส่วนเกี่ยวกับฉันใช้สำหรับอธิบายตัวตน ความสนใจ เป้าหมาย และประสบการณ์โดยรวมของผู้จัดทำ เนื้อหากล่าวถึงการเป็นนักเรียนชั้นมัธยมศึกษาปีที่ 6 แผนการเรียนวิทยาศาสตร์–คณิตศาสตร์ ความสนใจในการศึกษาต่อด้านเทคโนโลยีสารสนเทศ วิทยาการคอมพิวเตอร์ และการพัฒนาซอฟต์แวร์ รวมถึงความสนใจด้านระบบปฏิบัติการ ฮาร์ดแวร์ และการบำรุงรักษา Laptop

ส่วนทักษะจะแบ่งข้อมูลออกเป็นทักษะที่มีพื้นฐานและหัวข้อที่กำลังศึกษาเพิ่มเติม เพื่อให้เห็นพัฒนาการของผู้จัดทำอย่างตรงไปตรงมา ไม่ได้นำเสนอเฉพาะสิ่งที่ทำได้แล้ว แต่ยังแสดงให้เห็นถึงสิ่งที่กำลังเรียนรู้และเป้าหมายในอนาคตด้วย

ส่วนกิจกรรมใช้สำหรับแสดงประสบการณ์จากการเข้าร่วมการแข่งขัน การอบรม และกิจกรรมทางการศึกษา โดยมีการ์ดกิจกรรมที่สามารถกดเพื่ออ่านรายละเอียดเพิ่มเติมได้ รวมถึงมีรายการกิจกรรมในอดีตที่สามารถเปิดดูเพิ่มเติม และมีลิงก์ไปยัง Google Drive สำหรับดูรูปภาพกิจกรรมและเกียรติบัตรที่เกี่ยวข้อง

ส่วนผลงานและเป้าหมายใช้แสดงโครงงานและสิ่งที่ผู้จัดทำกำลังพัฒนา โดยแต่ละรายการมีสถานะของผลงาน คำอธิบาย และเทคโนโลยีหรือแนวคิดที่เกี่ยวข้อง ทำให้ผู้เข้าชมเห็นทั้งผลงานที่มีอยู่แล้วและหัวข้อที่ผู้จัดทำกำลังสนใจศึกษา

ส่วนคลังเกียรติบัตรใช้แสดงเกียรติบัตรที่ได้รับหรือกิจกรรมที่เข้าร่วม โดยแบ่งหมวดหมู่เป็นการอบรม การแข่งขัน และกิจกรรมประเภทอื่น ๆ รวมถึงแบ่งตามปีการศึกษา เพื่อให้สามารถค้นหาและดูข้อมูลได้เป็นระเบียบมากขึ้น

## รายละเอียดกิจกรรมและประสบการณ์

ภายในเว็บไซต์มีการรวบรวมกิจกรรมที่เกี่ยวข้องกับการเรียนรู้และการพัฒนาทักษะหลายรูปแบบ ตัวอย่างกิจกรรมที่นำเสนอ ได้แก่

- การแข่งขันตอบคำถามวิทยาศาสตร์และเทคโนโลยี ซึ่งเป็นกิจกรรมที่ต้องใช้ความรู้พื้นฐานด้านวิทยาศาสตร์และเทคโนโลยี รวมถึงการคิดวิเคราะห์และการทำงานภายใต้เวลาที่กำหนด
- กิจกรรมพัฒนาความสามารถในการคิดคำนวณ หรือการแข่งขันเกม 24 ซึ่งผู้จัดทำเข้าร่วมในฐานะตัวแทนห้องเรียน และได้รับรางวัลรองชนะเลิศอันดับที่ 2 ในสายการแข่งขันระดับมัธยมศึกษาปีที่ 4–6 กิจกรรมนี้ช่วยฝึกการคิดเลขอย่างรวดเร็ว ความแม่นยำ การตัดสินใจ และการแก้ปัญหาเฉพาะหน้า
- กิจกรรมวันวิทยาศาสตร์ ณ มหาวิทยาลัยราชภัฏนครสวรรค์ ซึ่งผู้จัดทำได้เข้าชมนิทรรศการและบูธกิจกรรม รวมถึงพูดคุยแลกเปลี่ยนประสบการณ์กับรุ่นพี่จากคณะเทคโนโลยีสารสนเทศและสาขาวิทยาการคอมพิวเตอร์ กิจกรรมนี้ช่วยให้เห็นภาพการเรียนต่อในระดับมหาวิทยาลัยและช่วยให้เข้าใจแนวทางการเตรียมตัวมากขึ้น
- การอบรมเชิงปฏิบัติการเกี่ยวกับการใช้ IoT เพื่อสร้างนวัตกรรม ซึ่งช่วยเปิดมุมมองเกี่ยวกับการนำอุปกรณ์และเทคโนโลยีมาเชื่อมต่อเพื่อแก้ปัญหา
- การแข่งขันสร้างสรรค์เกมจากคอมพิวเตอร์ ซึ่งเป็นประสบการณ์ที่เกี่ยวข้องกับการออกแบบแนวคิดและการพัฒนาเกม
- การอบรมและการเรียนรู้เกี่ยวกับ Google AI รวมถึงกิจกรรมที่เกี่ยวข้องกับเทคโนโลยี AI
- กิจกรรม Thailand CE-7 Moonshot Challenge และกิจกรรมการแข่งขันรูบิค ซึ่งช่วยส่งเสริมการคิดวิเคราะห์ ความรวดเร็ว และการแก้โจทย์ที่มีเงื่อนไข
- การอบรมด้านความเป็นผู้นำและการทำงานร่วมกับผู้อื่นจากประสบการณ์การเป็นสภานักเรียน

ประสบการณ์เหล่านี้ช่วยให้ผู้จัดทำได้พัฒนามากกว่าทักษะด้านวิชาการ เพราะยังได้ฝึกความรับผิดชอบ การเตรียมตัว การทำงานร่วมกับผู้อื่น การกล้าแสดงออก การจัดการเวลา และการเรียนรู้จากผลลัพธ์ของตนเอง

## ผลงานและโครงงานที่นำเสนอ

### 1. เว็บไซต์ Portfolio ส่วนตัว

เว็บไซต์ Portfolio นี้เป็นผลงานหลักของโปรเจกต์ จัดทำขึ้นเพื่อรวบรวมข้อมูลตัวตน กิจกรรม ผลงาน และเกียรติบัตร โดยผู้จัดทำได้วางโครงสร้างหน้าเว็บ ออกแบบรูปแบบการนำเสนอ เขียนโค้ด และปรับปรุงเนื้อหาด้วยตนเอง

ในการพัฒนาเว็บไซต์ ผู้จัดทำได้ทดลองออกแบบหน้าแรก ส่วนแนะนำตัว การ์ดแสดงผลงาน การ์ดกิจกรรม ส่วนเกียรติบัตร เมนูนำทาง และส่วนแสดงข้อมูลแบบโต้ตอบ โดยพยายามให้เว็บไซต์มีลำดับการนำเสนอที่ต่อเนื่องและสามารถใช้งานได้ทั้งบนหน้าจอคอมพิวเตอร์และอุปกรณ์ขนาดเล็ก

เว็บไซต์นี้ยังเป็นพื้นที่สำหรับทดลองแนวคิดใหม่ ๆ เช่น การเปลี่ยนข้อความบทบาทที่สนใจ การเปิดหน้าต่างรายละเอียดกิจกรรม การแสดงข้อมูลจากไฟล์ JSON การกรองประเภทเกียรติบัตร และการปรับเมนูให้เหมาะกับหน้าจอมือถือ

### 2. โครงงาน IS ด้านระบบปฏิบัติการคอมพิวเตอร์

เป็นโครงงานศึกษาค้นคว้าอิสระที่มุ่งศึกษาและเปรียบเทียบความแตกต่างของระบบปฏิบัติการ โดยมีการพิจารณาประเด็นต่าง ๆ เช่น ความเร็วในการบูตเครื่อง การใช้ทรัพยากรหน่วยความจำ ความอิสระในการใช้งาน ความสามารถในการจัดการงานเอกสาร และความเหมาะสมสำหรับการพัฒนาโปรแกรม

แนวคิดของโครงงานคือการเปรียบเทียบระบบปฏิบัติการจากการใช้งานและการทดลองจริง เพื่อทำความเข้าใจข้อดี ข้อจำกัด และความเหมาะสมของระบบในแต่ละสถานการณ์ โดยมีการศึกษา Windows 11 Pro และ Linux Mint รวมถึงการติดตั้งและทดลองใช้งานระบบปฏิบัติการ

จากโครงงานนี้ ผู้จัดทำได้เรียนรู้เกี่ยวกับการเก็บข้อมูล การกำหนดหัวข้อเปรียบเทียบ การสังเกตผลจากการทดลอง การวิเคราะห์ข้อแตกต่าง และการสรุปผลอย่างมีเหตุผล นอกจากนี้ยังได้เข้าใจมากขึ้นว่าการเลือกใช้ระบบปฏิบัติการควรขึ้นอยู่กับลักษณะงาน ทรัพยากรของเครื่อง และความต้องการของผู้ใช้งาน

### 3. EARTH NOTE แอปพลิเคชันจดบันทึก

EARTH NOTE เป็นแนวคิดแอปพลิเคชันจดบันทึกที่เกิดจากความต้องการสร้างแอปที่เหมาะกับรูปแบบการใช้งานของผู้จัดทำเอง ผู้จัดทำเริ่มจากการวางโครงสร้างแอป ออกแบบหน้าตา คิดฟังก์ชันที่ต้องการ และทดลองพัฒนาเป็นแอป Android

เนื่องจากผู้จัดทำยังอยู่ในช่วงเริ่มต้นของการศึกษา Android Development จึงใช้แนวทาง AI-Assisted Development โดยผู้จัดทำเป็นผู้กำหนดแนวคิด ฟังก์ชัน และ Logic ที่ต้องการ จากนั้นใช้ AI เป็นเครื่องมือช่วยเสนอแนวทางการเขียนโค้ด ช่วยอธิบายข้อผิดพลาด และช่วยแก้ปัญหาบางส่วน แล้วจึงนำโค้ดมาประกอบ ทดสอบ และปรับแต่งใน Android Studio ด้วยตนเอง

กระบวนการนี้ทำให้ได้เรียนรู้ว่า AI สามารถเป็นเครื่องมือช่วยในการเรียนรู้และพัฒนาซอฟต์แวร์ได้ แต่ผู้พัฒนายังต้องเข้าใจโครงสร้างของโค้ด ตรวจสอบผลลัพธ์ ทดสอบการทำงาน และตัดสินใจด้วยตนเองว่าแนวทางใดเหมาะสมกับโปรเจกต์

ปัจจุบันโปรเจกต์มีการแบ่งการพัฒนาเป็นหลายช่วง ได้แก่ BETA Version สำหรับทดสอบระบบและฟังก์ชันหลัก และ Thai Version (v0.1) ที่ปรับหน้าตาให้ใช้งานง่ายขึ้นและจัดทำเป็นไฟล์ APK สำหรับติดตั้งและทดลองใช้งานบนสมาร์ตโฟน

### 4. การศึกษา Local AI และ Open-Source Large Language Models

อีกหนึ่งเป้าหมายการเรียนรู้คือการศึกษาเทคโนโลยีปัญญาประดิษฐ์ โดยเฉพาะ Open-Source Large Language Models และการทดลองรันโมเดลแบบ Local บนคอมพิวเตอร์ส่วนตัว เช่น การทดลองใช้งานโมเดลในกลุ่ม Google Gemma และ Qwen ผ่านเครื่องมือที่ช่วยจัดการ Local AI

ความสนใจในหัวข้อนี้เกิดจากความต้องการทำความเข้าใจว่า AI ทำงานอย่างไรในระดับการใช้งานจริง และต้องการศึกษาความแตกต่างระหว่างการใช้งานโมเดลบนเครื่องส่วนตัวกับการเรียกใช้บริการผ่าน Cloud-based API การรัน Local AI ยังทำให้ได้เรียนรู้เรื่องทรัพยากรของเครื่อง ความเป็นส่วนตัวของข้อมูล การติดตั้งซอฟต์แวร์ และข้อจำกัดด้านประสิทธิภาพ

หัวข้อนี้ยังอยู่ในช่วงการศึกษาและทดลอง ไม่ได้อ้างว่าเป็นระบบ AI ที่พัฒนาขึ้นเอง แต่เป็นเป้าหมายที่ผู้จัดทำต้องการเรียนรู้ต่อเพื่อนำไปประยุกต์ใช้กับการพัฒนาซอฟต์แวร์ การแก้ปัญหา และการสร้างนวัตกรรมในอนาคต

## ทักษะที่มีและหัวข้อที่กำลังศึกษา

### ทักษะและความรู้ที่มีพื้นฐาน

- **HTML5**: การสร้างโครงสร้างหน้าเว็บ การแบ่งส่วนเนื้อหา การใช้ลิงก์ รูปภาพ ปุ่ม และองค์ประกอบที่เกี่ยวข้อง
- **CSS3**: การออกแบบสี ตัวอักษร การจัดวางองค์ประกอบ การสร้างการ์ด การจัดหน้าแบบยืดหยุ่น และการปรับรูปแบบให้เหมาะกับหน้าจอ
- **JavaScript**: การจัดการเหตุการณ์จากผู้ใช้ การควบคุมเมนู การเปิดและปิดหน้าต่าง การกรองข้อมูล และการเปลี่ยนเนื้อหาบนหน้าเว็บ
- **JSON และ Fetch API**: การแยกข้อมูลออกเป็นไฟล์ JSON และโหลดข้อมูลมาแสดงในหน้าเว็บไซต์
- **Git และ GitHub**: การจัดเก็บซอร์สโค้ด การเผยแพร่โปรเจกต์ และการติดตามการเปลี่ยนแปลงของงาน
- **Linux Mint**: การติดตั้ง ทดลองใช้งาน และศึกษาพื้นฐานของระบบปฏิบัติการ Linux
- **Laptop Maintenance**: ความรู้พื้นฐานเกี่ยวกับการดูแล ตรวจสอบ และบำรุงรักษา Laptop
- **AI-Assisted Development**: การใช้ AI เป็นเครื่องมือช่วยศึกษาโค้ด วิเคราะห์ข้อผิดพลาด และสำรวจแนวทางการพัฒนา โดยยังตรวจสอบและทดสอบผลลัพธ์ด้วยตนเอง

### หัวข้อที่กำลังศึกษาเพิ่มเติม

- แนวคิด JavaScript ระดับสูงและการจัดการโค้ดที่ซับซ้อนขึ้น
- Node.js และพื้นฐานการพัฒนา Backend
- Database และการจัดการข้อมูลด้วย Supabase
- System Architecture และ Hardware Architecture
- การติดตั้งและใช้งาน Open-Source AI แบบ Local
- การพัฒนาแอปพลิเคชัน Android
- การออกแบบประสบการณ์ผู้ใช้งานและการปรับปรุงเว็บไซต์ให้เข้าถึงได้ง่ายขึ้น

## เทคโนโลยีและเครื่องมือที่ใช้

- **HTML5** สำหรับกำหนดโครงสร้างและเนื้อหาของเว็บไซต์
- **CSS3** สำหรับออกแบบรูปแบบ สี การจัดวาง และการแสดงผลบนหน้าจอหลายขนาด
- **JavaScript** สำหรับเพิ่มการโต้ตอบและควบคุมการทำงานของหน้าเว็บ
- **JSON** สำหรับจัดเก็บข้อมูลประวัติ กิจกรรม และไทม์ไลน์
- **Fetch API** สำหรับโหลดข้อมูล JSON มาแสดงในหน้าเว็บไซต์
- **Google Fonts - Prompt** สำหรับการแสดงผลภาษาไทย
- **Git และ GitHub** สำหรับจัดเก็บและเผยแพร่ซอร์สโค้ด
- **GitHub Pages** สำหรับเผยแพร่เว็บไซต์ให้เข้าชมออนไลน์
- **Android Studio** สำหรับศึกษาและพัฒนาแอปพลิเคชัน EARTH NOTE
- **Linux Mint และ Windows 11 Home Single Language ** สำหรับการศึกษาและเปรียบเทียบระบบปฏิบัติการ
- **AI Tools** สำหรับช่วยศึกษาแนวทางการพัฒนา วิเคราะห์ข้อผิดพลาด และทดลองสร้างโค้ดในบางส่วน

## แนวทางการพัฒนาและการเรียนรู้

การพัฒนาเว็บไซต์นี้เป็นการเรียนรู้แบบลงมือทำ โดยเริ่มจากการกำหนดว่าต้องการนำเสนอข้อมูลอะไร จากนั้นจึงออกแบบลำดับเนื้อหาและสร้างโครงสร้าง HTML เมื่อมีโครงสร้างแล้วจึงใช้ CSS ปรับรูปแบบให้เหมาะสม และใช้ JavaScript เพิ่มการโต้ตอบที่ช่วยให้ผู้เข้าชมดูข้อมูลได้สะดวกขึ้น

ในระหว่างการทำงาน ผู้จัดทำต้องเรียนรู้จากปัญหาหลายด้าน เช่น การจัดวางองค์ประกอบให้ไม่ทับกัน การทำให้หน้าเว็บแสดงผลได้บนหน้าจอหลายขนาด การจัดการเส้นทางไฟล์รูปภาพ การโหลดข้อมูลจาก JSON การเชื่อมโยงปุ่มกับส่วนต่าง ๆ ของหน้า และการตรวจสอบข้อผิดพลาดจากการทำงานจริง

ผู้จัดทำมีการใช้ AI เป็นเครื่องมือช่วยในบางขั้นตอน เช่น ช่วยอธิบายแนวคิด ช่วยเสนอแนวทางการแก้ปัญหา ช่วยตรวจสอบโค้ด และช่วยสร้างตัวอย่างเพื่อใช้ศึกษา แต่ไม่ได้มองว่า AI เป็นผู้รับผิดชอบผลงานทั้งหมด เพราะผู้จัดทำยังเป็นผู้กำหนดความต้องการ เลือกแนวทาง ปรับโค้ด ตรวจสอบผลลัพธ์ และทดสอบการทำงานให้เหมาะกับเว็บไซต์ของตนเอง

สิ่งที่ได้เรียนรู้จากกระบวนการนี้คือ การพัฒนาโปรแกรมไม่ได้ประกอบด้วยการเขียนโค้ดเพียงอย่างเดียว แต่ยังรวมถึงการวางแผน การค้นคว้า การทดลอง การอ่านข้อผิดพลาด การปรับปรุงซ้ำ และการอธิบายเหตุผลของสิ่งที่สร้างขึ้นให้ผู้อื่นเข้าใจ

การทำเว็บไซต์ Portfolio ทำให้ผู้จัดทำได้ฝึกทั้งทักษะด้านเทคนิคและทักษะด้านการนำเสนอ โดยทักษะที่พัฒนาขึ้น ได้แก่

- การคิดและวางโครงสร้างข้อมูลก่อนเริ่มเขียนโค้ด
- การแบ่งงานขนาดใหญ่ออกเป็นส่วนย่อยที่สามารถพัฒนาและตรวจสอบได้
- การสร้างหน้าเว็บด้วย HTML และการออกแบบด้วย CSS
- การใช้ JavaScript เพื่อทำให้หน้าเว็บโต้ตอบกับผู้ใช้งาน
- การแยกข้อมูลออกจากโครงสร้างหน้าเว็บเพื่อให้ง่ายต่อการแก้ไข
- การจัดการไฟล์และโฟลเดอร์ในโปรเจกต์จริง
- การแก้ปัญหาจากข้อผิดพลาดที่เกิดขึ้นระหว่างการพัฒนา
- การค้นคว้าด้วยตนเองและการอ่านเอกสารทางเทคนิค
- การอธิบายผลงานและกระบวนการทำงานให้ผู้อื่นเข้าใจ
- การประเมินข้อจำกัดของผลงานและกำหนดเป้าหมายเพื่อพัฒนาต่อ

ในมุมมองของผู้จัดทำ ผลงานนี้จึงไม่ได้วัดความสำเร็จจากความสมบูรณ์ของเว็บไซต์เพียงอย่างเดียว แต่ยังสะท้อนความตั้งใจในการเรียนรู้ ความสม่ำเสมอในการพัฒนา และความกล้าที่จะทดลองทำสิ่งที่ยังไม่เคยทำมาก่อน

## แผนการพัฒนาต่อ

เว็บไซต์ยังอยู่ระหว่างการพัฒนาและสามารถเพิ่มความสามารถได้อีกหลายด้าน แผนการพัฒนาที่สนใจ ได้แก่

- ปรับปรุง Responsive Design ให้รองรับอุปกรณ์และขนาดหน้าจอได้หลากหลายขึ้น
- ปรับปรุงโครงสร้างโค้ดให้เป็นระเบียบและดูแลรักษาได้ง่าย
- เพิ่มระบบจัดการข้อมูลที่เชื่อมต่อกับ Database
- ศึกษาและทดลองใช้ Supabase สำหรับจัดเก็บข้อมูล
- เพิ่มระบบค้นหาหรือกรองข้อมูลกิจกรรมและผลงาน
- ปรับปรุงระบบแสดงผลเกียรติบัตรและเอกสารประกอบ
- เพิ่มรายละเอียดกระบวนการทำงานของแต่ละโครงงาน
- พัฒนา EARTH NOTE ต่อให้มีฟังก์ชันที่ครบถ้วนและใช้งานได้สะดวกขึ้น
- ศึกษา Backend และการสร้าง API
- เรียนรู้การนำ Local AI หรือ Open-Source AI มาประยุกต์ใช้กับโปรเจกต์
- เพิ่มการทดสอบและตรวจสอบการทำงานของเว็บไซต์อย่างเป็นระบบ
- ปรับปรุงการเข้าถึงเว็บไซต์สำหรับผู้ใช้งานที่มีความต้องการแตกต่างกัน

## วิธีเปิดใช้งาน

เว็บไซต์นี้เป็น Static Website จึงสามารถเปิดไฟล์ `index.html` ได้โดยตรง อย่างไรก็ตาม ภายในเว็บไซต์มีการโหลดข้อมูลจากไฟล์ JSON ด้วย `fetch()` ดังนั้นแนะนำให้เปิดผ่าน Local Server เพื่อให้การโหลดข้อมูลทำงานได้สมบูรณ์

### เปิดผ่าน Visual Studio Code และ Live Server

1. เปิดโฟลเดอร์โปรเจกต์ด้วย Visual Studio Code
2. ติดตั้งส่วนขยาย Live Server หากยังไม่มี
3. คลิกขวาที่ไฟล์ `index.html`
4. เลือก **Open with Live Server**
5. เว็บไซต์จะเปิดในเบราว์เซอร์ผ่าน Local Server

### เปิดเวอร์ชันออนไลน์

เว็บไซต์เวอร์ชันออนไลน์สามารถเข้าชมได้ที่ [GitHub Pages](https://fumisaki-g.github.io/Portfolio/)

## สถานะของผลงาน

เว็บไซต์อยู่ในสถานะ **กำลังพัฒนาและปรับปรุงอย่างต่อเนื่อง** โดยส่วนหลักของเว็บไซต์สามารถใช้สำหรับนำเสนอประวัติ กิจกรรม ผลงาน และเกียรติบัตรได้แล้ว แต่ยังมีบางส่วนที่ผู้จัดทำต้องการศึกษาและพัฒนาต่อ เช่น Backend, Database, Android Development, Local AI และการปรับปรุงประสบการณ์การใช้งาน

การระบุสถานะว่ากำลังพัฒนาเป็นส่วนหนึ่งของการนำเสนอผลงานอย่างตรงไปตรงมา เพราะผู้จัดทำต้องการให้เห็นว่าเว็บไซต์นี้เป็นผลงานที่เติบโตไปพร้อมกับการเรียนรู้ ไม่ใช่ผลงานที่หยุดอยู่เพียงเวอร์ชันเดียว
